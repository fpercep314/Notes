## Resumen del proyecto

Plataforma colaborativa para pequeños equipos que permite almacenar, organizar y compartir apuntes en texto plano y archivos multimedia. Incluye autenticación, CRUD completo, sistema de etiquetas flexible, búsqueda integrada y sincronización en tiempo real. Interfaz moderna en una sola página para acceso instantáneo desde cualquier dispositivo.

## Stack tecnológico

- Java / Spring Boot
- React + TypeScript
- Tailwind CSS
- PostgreSQL
- Docker Compose
